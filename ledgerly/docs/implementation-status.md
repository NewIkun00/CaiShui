## 当前验证结果

- ESLint：通过。
- TypeScript 严格类型检查：通过。
- 单元/应用/契约测试：当前 **56 个测试文件、200 项测试**通过。身份测试覆盖 Provider subject 幂等关联、一次性 state 防重放、PKCE、事务 Cookie 篡改、JWT/JWKS 签名与 issuer/audience/nonce/时间校验、会话过期/撤销、Provider 撤销失败时本地优先失效、开发/正式模式边界、租户成员与公司范围，以及 OIDC Web 请求剥离开发身份头。
- 数据库迁移：当前 `0000`–`0036` 共 **37 个顺序迁移**；身份基础迁移增加正式用户、外部身份、会话、邀请、租户成员角色和平台运营角色；`0035` 追加邀请脱敏提示，`0036` 增加短时、一次性消费的 OIDC 登录状态，未修改历史迁移。
- Web 生产构建：通过，当前 **18 个产品页面、20 条静态路由**；`/filings` 已覆盖征期任务、申报包冻结、回执/完税凭证、关闭、四类调整工单和年度可移植档案下载。
- API 启动及 R2 冒烟流程：通过；首次生成 1 项、重复生成 0 项、逾期派生正确、测试日历的生产用途被阻断，并完整流转到“已缴款/已完成”。
- R3 页面验收：通过；computer-use 在 3020 端口核对完整布局、测试/生产边界，并通过页面创建版本化测试 SOP。验证后 3001、3020 服务已停止。

# 账税通界面设计系统 v3

本文件是前端后续开发必须遵循的视觉与体验约束。v3 在桌面交付包 `账税通-界面重设计-v2` 的基础上，引入 AI 原生产品的安静界面、命令式导航和上下文建议，但工程代码不依赖外部文件夹，换电脑后仅凭仓库即可继续维护。

## 参考原则

设计只吸收原则，不复制 ChatGPT、Gemini 或腾讯元宝的品牌外观：

- ChatGPT：让内容与当前任务成为视觉中心；系统控件克制，强调色只标记关键操作、选中和焦点；提供随时可用的命令入口。
- Gemini / Material 3：使用语义化颜色角色、分层 surface 与角色化字号；不同断点保持相同语义，不因屏幕变化改变状态含义。
- 腾讯元宝 / TDesign：优先保障中文阅读节奏和复杂业务场景的一致性；降低学习成本，让高频任务能快速抵达。
- 财税产品自身约束：智能能力只提供建议、草稿和线索，不能掩盖来源、假装完成专业判断或跳过人工确认。

## 设计目标

- 欧美企业软件风格：简约、克制、信息密度稳定。
- 浅色中性灰作为主体，品牌蓝只承担操作、选中和焦点状态，占页面面积不超过约 8%。
- 默认不使用渐变和重阴影，通过白色承载面、浅灰背景与 1px 描边分层；只有浮层和当前建议允许使用轻量层级阴影。
- 财税状态必须明确：普通完成状态使用中性灰，待确认使用橙色，阻断和高风险使用红色。
- 每个关键结论应能回到来源、规则版本和人工复核记录。

## 工程入口

- 全局 Token 与兼容层：`apps/web/app/design-system.css`
- 应用框架与导航：`apps/web/app/ui/app-shell.tsx`
- 登录与注册结构：`apps/web/app/auth-start-panel.tsx`
- 初始化工作台：`apps/web/app/dashboard/page.tsx`

`design-system.css` 必须在旧页面样式之后加载。旧模块可以逐页迁移，但新增代码只能使用该文件定义的 Token，不得新增相近但不同的蓝色或灰色。

## 布局与组件

- 桌面侧栏宽 232px，顶栏高 64px，内容区默认内边距 42px 48px 64px。
- 导航按业务链路分组；选中态使用中性灰底、2px 蓝色指示条，避免导航区域大面积使用品牌色。
- 卡片圆角 14px，输入框和按钮圆角 9px。普通卡片接近无阴影；当前建议、命令面板等临时高层 surface 使用轻阴影。
- 控件高度至少 40px；焦点态必须保留可见蓝色焦点环。
- 表格正文 13px，行高 48px；金额、日期和编号优先使用等宽字体。
- 状态优先使用有语义的文字，不使用大面积彩色色块或药丸标签。
- 页面标题统一使用蓝色短竖线 eyebrow、30px 主标题和 13px 说明文字。
- 顶栏全局命令搜索通过 `⌘ K` / `Ctrl K` 聚焦，可按功能名称或导航分组快速跳转；新增路由时必须同步加入统一导航配置。
- 工作台先显示“建议的下一步”，且建议必须由真实业务状态确定，不能伪装成模型推理结果。
- `Esc` 关闭命令搜索和帮助浮层；所有浮层必须有明确标题、关闭方式和键盘焦点反馈。
- 非交互元素不得使用按钮样式。暂未实现的功能不要留下误导性点击入口。
- 过渡时长保持在 150–200ms；必须通过 `prefers-reduced-motion` 尊重减少动态效果的系统设置。

## 响应式规则

- `>1180px`：完整侧栏、搜索框和三列初始化卡片。
- `821–1180px`：隐藏全局搜索，初始化卡片变为两列。
- `<=820px`：侧栏转换为横向导航，页面内容单列，登录品牌面板隐藏。
- `<=520px`：标题缩小，顶栏和卡片进一步收紧。

## 禁止事项

- 不重新引入旧绿色主色或黄色主色。
- 不使用渐变背景、玻璃拟态、重阴影和超过 16px 的容器圆角。
- 不在单个页面复制 App Shell、按钮或状态样式。
- 不用颜色作为唯一状态信息；状态必须同时有清晰文字。
- 不为追求视觉效果隐藏风险、来源、版本或阻断原因。
- 不使用“AI 已决定”“自动完成”等语言描述确定性规则或尚未接入的模型能力。
